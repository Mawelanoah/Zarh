# Zarh Wellness Lounge — Website Demo

A responsive, one-page website concept built from the supplied Zarh Wellness Lounge price list.

## Files
- `index.html` — website structure and service information
- `style.css` — responsive layout, styling, and mobile navigation presentation
- `script.js` — mobile menu and service-specific WhatsApp enquiry buttons

## Preview locally
Open `index.html` in a browser. An internet connection is needed for the Google Fonts and remote demonstration photos.

## Publish with GitHub Pages
1. Open **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
3. Wait for GitHub Pages to publish the site (usually 1–2 minutes).
4. The live URL will be: **https://mawelanoah.github.io/Zarh/**

## Before showing it as a finished business website
- Ask the owner to approve the layout and wording.
- Replace the illustrative spa photos with photos approved by the owner where possible.
- Confirm service names, prices, and durations against the latest price list.
- Confirm the phone number, location pin, opening hours, and booking rules.
- The opening hours are not listed because they were not included in the supplied image.
- This is a front-end demo only. It does not include an admin dashboard, database, automatic appointment availability, online payments, or booking storage.
- The WhatsApp buttons open a pre-filled enquiry. The customer still sends the message and the owner confirms availability.
