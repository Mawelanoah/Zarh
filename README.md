# Zarh Wellness Lounge

Professional multi-section website for Zarh Wellness Lounge — massage and facial treatments in Bizana, Eastern Cape.

## Files
- `index.html` — full website structure
- `style.css` — responsive styles and layout
- `script.js` — mobile menu, treatment tabs, WhatsApp booking buttons, gallery lightbox

## Live site
Once GitHub Pages is enabled (Settings → Pages → Deploy from branch `main` / root):

**https://mawelanoah.github.io/Zarh/**

## Features
- Sticky header with functional mobile hamburger menu
- Premium hero with clear call-to-action
- Treatment catalogue with Massage / Facial tabs
- Individual WhatsApp enquiry buttons (pre-filled with service + price)
- Combo deals section
- About section
- Photo gallery with simple lightbox
- Contact & location with Google Maps link
- Floating WhatsApp button
- Fully responsive (mobile-first)
- No fabricated reviews, hours, or claims
