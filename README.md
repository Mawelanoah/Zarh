# Zarh Wellness Lounge

Premium multi-section website for Zarh Wellness Lounge — massage and facial treatments in Bizana, Eastern Cape.

## Live site
https://mawelanoah.github.io/Zarh/

## Features
- Sticky header with working mobile hamburger menu
- Premium hero with overlay and clear CTAs
- Treatment catalogue with Massage / Facial tabs
- Individual “Book This” buttons that open the Booking Assistant pre-filled
- Interactive multi-step **WhatsApp Booking Assistant**
- Combo deals section
- About, gallery (with lightbox), contact & directions
- Floating Booking Assistant + WhatsApp buttons
- Back-to-top button
- Fully responsive, mobile-first
- No fake reviews, invented hours, or unconfirmed claims

## Booking Assistant
A guided enquiry form (not a real chatbot or availability checker).  
It collects treatment choice, preferred date/time, and optional name, then opens WhatsApp with a clear pre-filled message.  
Appointments are confirmed only when the business replies.

## Files to upload
- `index.html`
- `style.css`
- `script.js`
- `README.md`

## Publish / update on GitHub Pages
1. Replace the four files in the repository root.
2. Settings → Pages → Deploy from branch `main` / root.
3. Wait 1–2 minutes for the live site to update.
